Antes de Grade Uploader: lo básico de Git.

Esta página existe para quienes nunca usaron Git ni GitHub. No hace falta ser programador — solo necesitás entender tres o cuatro ideas y elegir la forma de "bajar" el proyecto que te resulte más cómoda.

💡 Tranquilidad primero: lo único que vas a hacer con este proyecto es descargarlo y, de vez en cuando, actualizarlo. No vas a "romper" nada del repositorio original por más que hagas clic de más.
Lo primero

¿Qué es Git? ¿Qué es GitHub?

Git es un programa que guarda el historial de cambios de un proyecto de código — algo parecido a "Control de cambios" de Word, pero mucho más potente. Grade Uploader es un proyecto de código, así que vive dentro de un sistema Git.

GitHub es un sitio web que aloja proyectos Git en línea para que cualquiera pueda verlos y descargarlos. github.com/chhdeza/grade-uploader es la página de GitHub donde vive Grade Uploader.

En una frase: Git es la herramienta, GitHub es el sitio web donde ese proyecto está guardado. Necesitás Git instalado en tu computadora solo si vas a usar la opción de línea de comandos (más abajo hay opciones que ni siquiera lo requieren).

PASO 01
Solo si vas a usar la terminal

Instalar Git en Windows

Si preferís las opciones sin terminal (más abajo), podés saltarte este paso. Si querés usar git clone como en el taller principal:

  • Entrá a git-scm.com/download/win — la descarga arranca sola.
  • Abrí el instalador y hacé clic en "Next" en todas las pantallas — las opciones por defecto sirven perfectamente.
  • Al terminar, abrí PowerShell o el Símbolo del sistema (buscá "cmd" en el menú de inicio) y escribí:
git --version

Si te responde algo como git version 2.4x.x, ya quedó instalado. Si dice que no reconoce el comando, cerrá y volvé a abrir la terminal (a veces hace falta reiniciar la PC).

📦 La más simple

Descargar ZIP

Clic en "Download ZIP" → extraés la carpeta → listo. No instalás nada. Para recibir una actualización, hay que volver a descargar el ZIP completo y reemplazar la carpeta.

🖥️ Sin escribir comandos

GitHub Desktop

Clic en "Open with GitHub Desktop" (la primera vez te pide instalarlo). Después, todo se maneja con botones: "Clone", "Fetch origin", "Pull origin" para actualizar.

⌨️ La del taller principal

Terminal con git clone

Copiás la URL HTTPS, abrís una terminal y corrés git clone. Es lo que hace instalar.bat por vos automáticamente.

PASO 02
Lo mínimo indispensable

Comandos básicos de Git que vas a necesitar

Como solo vas a usar el proyecto (no a modificarlo y subir cambios), necesitás apenas dos comandos. El resto es referencia por si te sirve.

ComandoPara qué sirve
git clone <url>Descarga el proyecto por primera vez, dentro de una carpeta nueva.
git pullTrae los cambios más recientes del repositorio — así actualizás sin volver a descargar todo.
cd nombre-carpetaCambia la carpeta activa en la terminal (hay que estar "dentro" del proyecto para que git pull funcione).
git statusMuestra el estado actual — útil para confirmar que todo está al día.

No vas a necesitar git add, git commit ni git push para este proyecto — esos son para quienes modifican el código y suben cambios, no para quienes solo lo usan.

Más adelante

¿Cómo actualizo Grade Uploader cuando salga una versión nueva?

Depende de cómo lo hayas obtenido:

  • Si usaste git clone: abrí una terminal dentro de la carpeta del proyecto y corré:
cd grade-uploader
git pull
  • Si usaste GitHub Desktop: abrí la aplicación y hacé clic en el botón "Fetch origin" (que cambia a "Pull origin" si hay novedades).
  • Si descargaste el ZIP: no hay atajo — volvé a la página del proyecto, descargá el ZIP de nuevo y reemplazá la carpeta anterior.
Por si te cruzás la palabra

Mini-glosario

  • Repositorio (repo): la carpeta del proyecto, con todo su historial de cambios incluido.
  • Clonar: descargar una copia completa de un repositorio a tu computadora.
  • Commit: un "punto guardado" en el historial — cada vez que alguien cambia el código, queda registrado como un commit.
  • Rama (branch): una línea de trabajo separada dentro del mismo proyecto. Para usar Grade Uploader nunca vas a necesitar crear una.
  • Pull: traer a tu computadora los commits nuevos que otra persona subió al repositorio.
Cuando algo no sale

Preguntas frecuentes

La terminal dice "git no se reconoce como un comando interno o externo"

Git no quedó instalado correctamente, o la terminal se abrió antes de instalarlo. Cerrá la terminal, volvé a abrirla (o reiniciá la PC) y probá git --version de nuevo. Si sigue fallando, reinstalá desde git-scm.com.

No quiero instalar nada, ¿hay una opción sin Git?

Sí — "Download ZIP" (opción 3 más arriba) no requiere instalar Git en absoluto. También podés usar el .exe ya generado del script, mencionado en la guía principal del taller.

¿Puedo dañar el proyecto original en GitHub por usarlo mal?

No. Mientras solo clones, descargues o actualices (pull), estás siempre "leyendo" — nunca escribís nada en el repositorio original de GitHub.

GitHub Desktop me pide iniciar sesión, ¿es necesario?

Para clonar un repositorio público como este, no es obligatorio, pero GitHub Desktop suele pedir una cuenta gratuita de GitHub para funcionar cómodamente. Podés crear una en segundos si no tenés.
